# 设计模式已死？

- 发布时间: 2026-06-09

AI时代下设计模式的永恒价值：单例、工厂、观察者等经典模式在AI编程中自发重现，揭示软件工程底层规律。从并发安全单例到多Agent系统设计，传统模式在AI Agent系统中以新形式回归。

## 核心观点

当AI系统拥有足够复杂的任务和自治能力时，它最终会收敛到与人类工程设计相同的底层抽象。不管编程范式如何变化，经典始终是经典。

## 覆盖的设计模式

| 模式 | 类型 | AI Agent 时代的新应用 |
|------|------|---------------------|
| 单例模式 | 创建型 | 全局配置管理、Agent 共享状态、并发安全（sync.Once） |
| 工厂模式 | 创建型 | 根据任务类型创建不同 Agent、工具实例化 |
| 观察者模式 | 行为型 | Agent 间事件通知、状态变更广播 |
| 装饰者模式 | 结构型 | Agent 能力动态增强、中间件链 |
| 策略模式 | 行为型 | 运行时切换推理策略、不同任务用不同算法 |
| 适配器模式 | 结构型 | 不同 LLM API 适配、工具接口统一 |
| 代理模式 | 结构型 | Agent 代理、延迟初始化、访问控制 |
| 命令模式 | 行为型 | 任务封装、撤销/重做、批处理调度 |
| 组合模式 | 结构型 | Agent 层级结构、Multi-Agent 树状组织 |
| 迭代器模式 | 行为型 | 顺序访问聚合对象、遍历 Agent 结果集 |

## 关键洞察

1. **设计模式没有死** — AI 自发地演化出了类似设计模式的结构
2. **Harness 本身也跟设计模式有关** — 任务拆分、Agent 编排本质上是对经典模式的新应用
3. **治愈 AI FOMO 焦虑** — 底层抽象是不变的，上层范式在变
